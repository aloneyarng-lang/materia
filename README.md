# Materia 2.4.0

阅读器新增逐行高亮与下划线，划词后按 H / U 即可保存，Ctrl+Z 撤销新建文字标记；F 切换专注阅读。连续页面保持稳定大小与清晰度，长选文使用紧凑批注工具。更新后请完全退出并重新打开 Materia。

## 2.4.0 完整机器学习引擎

材料预测已接入完整 Python / NumPy / SciPy / scikit-learn 科学生态，提供 8 类经典回归算法、嵌套分组验证、自动调参、诊断图、可追溯训练报告、模型保存重载和批量 CSV 预测。运行环境随桌面软件打包。旧数据与模型保留，新训练使用成熟库官方实现。


性能预测已升级为通用材料机器学习模块：可按任意材料类型、at.%／wt.%／mol.%／化学计量式和自定义结构、工艺、计算、测试描述符建立数值回归模型，并显示交叉验证误差带、主要输入与适用域提示。旧版非晶粉末数据和模型保持兼容。

恢复原有 Mac 圆角、顶部五个标签的液态玻璃选中层、高光阴影和按压回弹。功能整合与模块机制保留；新增布局样式不再覆盖原主题的圆角、材质和配色。

主页面与工具入口已收拢：顶部切换星图、文献、材料、笔记和性能预测，侧栏只管理文献范围与分组。标签目录归入笔记，参数对照与绘图共用工作区，外观归入设置。设置中的“功能管理”可停用或恢复可选页面，保留原数据。模块接口及扩展方法见 [MODULES.md](material-atlas/MODULES.md)。

主页“笔记”右侧新增“性能预测”：导入 Excel／CSV 实验数据、训练本地模型、输入元素配比与条件预测性能，并支持新增性能指标。预测数据与模型可在该页面单独导出备份。使用说明见 [PREDICTION.md](material-atlas/PREDICTION.md)。

系统界面现支持中文、English、日本語、Deutsch。通过齿轮 →「设置」→「界面语言」切换，即时生效并记住本机选择。

AI 划词翻译弹窗的「译成」支持中文、英语、日语、德语，并与阅读器「译文」页同步、记住目标语言。

文献标题、标签、笔记与 PDF 原文保留原文。

双击本文件夹中的「启动 Materia.cmd」启动；更新后请完全退出并重开。现有本地快捷方式会在部署时更新。

- 主题整理为澄璃、北航蓝、纸白、学术紫、暖砂、博丽灵梦、命运石之门 7 款，每款支持浅色和深色，统一使用透明玻璃、圆角与按压回弹。
- 主界面支持未读 ⚪、在读 🟡、精读 🟢、归档 🟣 四种阅读状态，支持快速筛选和批量设置，与文件夹分组独立。
- 星图右下角可一键自然整理；右键提供释放固定后整理和撤销。
- 文献列表、星图和分组新增／整理了右键操作，收起冗余提示；材料批量操作集中到「整理」。
- 默认文献库位于本文件夹的「文献库」。软件分组对应 papers 子文件夹，文件夹内新建、移动和改名会自动同步；原有录入信息保留。
- 「设置」最底部可查看每日导入绿色热力图。

旧默认文献库 `material-atlas/release/Materia-win32-x64/文献库` 保留为迁移备份。自定义选择的其他文献库不强制搬迁。

主题制作规范与校验入口：`material-atlas/theme-examples/DESIGN_RULES.md`、`AGENTS.md` 和 `scripts/validate-theme-design.mjs`。源码与完整说明位于 material-atlas。

## 2.0.1 本地程序更新修补

在 material-atlas 目录运行 `npm run deploy:local`，从当前源码构建并更新到工作区的 `Materia-win32-x64`，保留程序文件备份和文献配置。关闭旧程序后再执行，完成后使用工作区「Materia 最新版」快捷方式。源码更新不等于正在运行的 EXE 已更新。

整合厂商列表与自动模型发现，保留 Gemini 校验、Claude 原生协议、自定义配置以及已安装苹方的 Codex 主题。
