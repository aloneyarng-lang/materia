# AI 研究助手

从左侧工具栏的「AI 研究助手」线性对话图标或展开导航后的同名入口打开。

## 配置与使用

选中 Amadeus，点击右下九宫格的播放按钮，每点一次按「自动 → 空格 → 暂停 → 自动」循环一档。自动模式按段播放台词，空格模式等你按空格再播下一句，暂停模式停在当前台词。播放期间发送的消息会排队，等本批台词或普通回复的全部朗读段落播完，再按发送顺序处理。已经显示的台词和你的消息按顺序存入同一条本地记录，可以从「记录」查看，也可用「保存」导出 Markdown。

自动对话会把近期聊天和对话摘要发给已配置的模型，占用模型额度。「记录」从右侧滑出并跟随新台词，往上翻阅时保持阅读位置。打开设置、工具、记忆或记录，以及浏览历史列表时，播放模式和当前配音保持原样。离开助手或切换对话时会停止当前播放。

当需要选择讨论方向、偏好或下一步时，AI 可给出三个可选回复，显示为画面中部的半透明选项条。悬停或点击会提亮，点击后继续对话，输入框中尚未发送的草稿会保留。选项会随历史记录保存，也会包含在后续对话上下文中；普通问答可以直接回答。

自动对话通常生成 1 到 4 句台词，逐句播放，说够了就等你接话。一句有效台词也可播放。每批自动对话约有 40% 的机会在最后一句给出三选一。播放中可以暂停或提前排队发送消息。

红莉栖在没有用户发言时，从随对话轮换的日常话题简短开口，最多两句。有用户发言后，自动对话沿着实际交流继续，最多四句。重开自动对话时，最后一次用户发言之后、尚未得到回应的自动台词及对应旧摘要不进入续聊提示。旧独白保留在记录里，用户接话后可继续讨论。旧版默认性格会自动更新为新版，自定义性格保留。

角色会参考前几轮原话，在接话时保留尚未解决的分歧和已经说过的承诺。自动对话的摘要记录已发生的交流，近期原话优先。连续播放的自动台词在模型上下文中合为一条发言，让前面的用户原话仍有机会被看到。界面和历史逐句保留。

左上角可切换 Amadeus 和 DeepSeek 娘，两者分别保存角色卡。切换会新建对话，历史对话继续使用当时的角色设定。DeepSeek 场景使用本地 Workshop 3787353838 的视频，开启动态后，发送消息会触发看手机、去电脑前、返回床上的完整片段。回复提前结束也会继续播放动作；动作期间再次发送会保留一次后续触发。

动作映射集中在 `dist/agent-actors.js`，通过事件名映射到片段序列，播放器位于 `dist/agent-actions.js`。扩展指令时，增加片段与事件映射，再由对应业务调用 `characterStage.trigger(事件名)`。切换角色、隐藏窗口或关闭动态时会停止或暂停对应场景播放。

### Amadeus 通话动作样片

通话场景以现有红莉栖立绘为参考。已通过用户预览的开场样片包含抬手招呼、放下手、翻开笔记和低头写字，见 [本机样片](<../.local/红莉栖-Veo-脸部微调.mp4>)。这条素材使用 Veo 生成连续动作，随后剪掉开头约 1.5 秒裁到脸部的画面，静音并用相邻帧的运动信息轻微稳定脸部，保留原片的表情和肢体动作。样片为独立预览文件，时长约 8.5 秒。

三条通话原片已按动作拆成 11 个[透明素材片段](<../.local/红莉栖-透明动作素材/>)，统一导出为静音的 1280×720、24 fps VP9 WebM，保留透明通道。编号 01–03 是招呼、翻笔记和写字，04–07 是伸展、放下手、移开视线和看回镜头，08–11 是示意稍等、转身取资料、举起资料和阅读。素材待接入。抠像时单独检查伸出的手、发丝和纸张等道具，导出后解码核对透明通道并叠到浅色、深色底图上检查。同一原片内保留相邻帧，跨原片切换前需要核对立绘大小与首尾姿势。

红莉栖眨眼采用独立闭眼素材与眼睑分层合成，过渡限制在眼部小区域，避免流向图拉扯眼睛和眉毛。背景复用了原场景的脉动纹理，加入独立的缓慢流动、明暗变化和粒子运动，仍采用浏览器兼容渲染，未接入系统音频响应。

助手采用整屏场景、中央 Amadeus 立绘与底部横向对话框的构图。右下角「设置」包含「AI 服务」与「角色卡」。在红莉栖场景中还可打开「记忆库」。「角色动态」在角色卡页，系统的减少动态效果设置也会生效。

「角色卡」可编辑角色名、性格、开场白，导入或导出 JSON，也可导入 Character Card V2 的 JSON。自定义形象支持不超过 2 MB 的 PNG、JPEG 或 WebP。保存角色卡会开始新对话，已有对话可从「历史对话」恢复，继续使用当时的性格设定。

角色卡还可编辑「角色背景」和「示例对话」。导入 SillyTavern 的 Character Card V2 JSON 时，识别角色描述、性格、开场白和 `mes_example`。示例可用独立一行的 `<START>` 分段，用 `{{user}}` 与 `{{char}}` 标记说话人。普通回复和自动对话都把示例当作口吻参考，并与真实聊天及记忆区分。红莉栖、蕾塞和甘雨自带原创口吻示例，角色卡内填写的示例优先。日常回复按纯台词生成。

「记录」显示当前对话完整内容。「快存」可导出 Markdown。日常问题可以直接交流，研究问题继续使用文献检索工具与来源引用。

Windows 桌面版配置好本地 GPT-SoVITS 后，普通回复和 Amadeus 自动台词默认用红莉栖音色朗读。右下九宫格的「配音」开关会记住选择。「停止」或离开助手会打断当前朗读。发送新消息会保留当前及后续已排好的朗读。切换角色、聊天或文献库时，尚未发送的消息放回输入框供编辑。启用配音时，模型会在一次回复中生成屏幕文字与对应朗读稿。首句采用短台词，当前句开始播放时显示对应文字，播放期间准备下一句。完整回复可在「记录」查看。代码块与文献引用保留在文字回复中。配音失败时，文字回复仍可阅读。

「设置 → 语言」分别设置 Amadeus 的「回复语言」和桌面助手的「配音语言」。例如，回复选简体中文，配音选日本語，屏幕和历史记录显示中文，播放器朗读日文。当前 AI 服务会同时生成所选语言的回复和朗读稿。模型未按配对格式返回时，使用独立翻译请求兼容，会额外占用模型额度。选「跟随回复」即可直接朗读。

Materia 的配音使用角色与配音语言对应的固定参考和原有朗读设置。情绪配音试验已于 2026-11-10 [归档](<../../codex workspace/history/20261110_materia-voice-emotions/ARCHIVE.md>)。

DeepSeek 娘使用真由理的 GPT-SoVITS v2 社区专模，配置在用户目录的 `.materia/voice/deepseek.json`。模型提供中、日、英朗读，默认中文，已有配音语言设置优先。固定参考使用原版《命运石之门》的日语语音 `MAY_0053`，已与本机游戏资源核对。角色声线随左上角的角色选择切换。[权重来源](https://huggingface.co/SteinsGateSg/mayuri-voice/tree/1471e5b0faf57dd490280f74417d7711a5af9e06)

## 朗读器和记录重读

九宫格「工具 → 朗读器」接受最多 2400 字，选择中文、日语或英语后，用当前 AI 服务翻译，再以当前角色声线逐句朗读。API 和本地反重力共用已配置的服务入口。窗口显示译文，支持停止和点击句子重读，并保留当前文献库最近 100 段朗读入口。

工具选择菜单和朗读器使用浅色底，记录面板使用浅紫色玻璃背景及深色文字。后续修改这些区域时保持这一配色偏好。

朗读器采用原文与译文对照布局，语言选择位于上方，状态及播放操作位于底部；窄窗口改为上下排列。当前译文的句尾直接提供 ▶，最近朗读折叠收起。

「记录」从当前聊天的 `entries` 逐条显示文本，内容写在文献库的 `ai-chats.json`。连续自动台词仅在构建模型上下文时合并。显示记录、保存记录和发给模型的上下文需分别验证。

生成的配音默认保存为当前文献库的 `.agent-voice/<SHA-256>.wav`。聊天条目通过 `voiceClips` 保存句子、语言及文件标识，音频单独存放。记录和朗读器里的句子末尾使用 ▶ 按钮重播。旧记录没有保存过的声音，首次点击句子会按当前配音语言生成并保存。已有音频重播直接读取本机文件。

语音写入先完成临时文件再换名，同内容按音频散列复用。保存及读取时核对文献库标识，避免切换文献库后把语音附到另一份聊天上。


配音模型和运行环境位于当前 Windows 用户目录下的 `.materia/voice`，通过本地进程合成语音。启用配音时，打开 Materia 会在后台预热中日文合成。语音进程保留可复用的显存缓存，每 32 次清理一次，缓存超过 3 GB 或合成失败时也会清理。单句使用专门的单句推理路径；本次运行中最近八条较短台词的音频可直接复用。关闭 Materia 时配音进程随程序退出。

1. 点击右上角「对话操作 → 服务设置」，从「AI 服务厂商」选择厂商，填入该站点的 API 密钥。停止输入后自动查询模型列表，也可点击「刷新模型」。查询只获取列表，不提交问题、文献或生成请求；不会自动保存密钥或设置。
2. 从「可用模型」选择模型并保存。列表以服务实时返回为准，不维护固定的模型清单；列出不代表账号已获全部调用权限，研究助手需模型支持工具调用。旧设置中的模型不会因刷新列表而丢失。列表获取失败时可勾选「手动填写模型 ID」。「自定义服务 / 本机模型」保留地址、模型和 Chat Completions / Responses / Claude Messages 协议设置，本机服务可留空密钥。
3. 保存设置，选择「整个文献库」或「当前选中文献」。后者使用列表中勾选的文献；未勾选时使用当前打开的文献。空选择会阻止发送，不会退回全库。
4. 提问，例如「检索高熵合金相关文献」「根据笔记梳理信息缺口」「比较已录入的屈服强度，保留样品、单位和测试条件」。支持 `Ctrl+Enter` 发送、多轮追问、停止生成及新对话。
5. 回答中的有效引用和下方「本次检索来源」可点击打开对应文献详情。切换文献范围会新建对话，原对话保存在历史中。切换文献库会停止当前请求并读取新文献库的聊天历史。

启动桌面版：在本目录运行 `npm install`、`npm start`。浏览器预览：`npm run preview`，打开终端显示的本机地址。原始文献库的浏览器与桌面存储相互独立。

聊天中的提问和回答以 Markdown 排版，支持标题、加粗/斜体、列表、表格、引用、链接、行内代码和代码块。有效文献引用仍可点击跳转；代码里的引用保持原样。表格与长代码可横向滚动，网页链接在外部浏览器打开。HTML 原样显示，Markdown 图片显示替代文本，不加载远程图片。

## Google AI Studio / Gemini 配置

Google 官方兼容地址填写 `https://generativelanguage.googleapis.com/v1beta/openai`，协议选择 **Chat Completions**。当前适配器会明确拦截此地址与 Responses 协议的错误组合；Google 原生 `/v1beta` 地址不能直接作为 OpenAI 兼容地址使用。`AQ.` 前缀的新密钥可以正常填写。

「测试连接」只查询模型列表，不发送问题或文献，也不保存表单。程序识别 Gemini 模型 ID 的 `models/` 前缀；列表没有匹配项时会显示服务返回的部分 Gemini ID，并在模型输入框提供候选项。选择确切 ID 后重新检测，再点击「保存设置」。HTTP 200 表示服务接受了模型列表请求，不代表已经验证模型生成、工具调用、地区权限或额度。没有开启系统加密记住密钥时，重启后仍需重新填写。

官方说明：[OpenAI 兼容接口](https://ai.google.dev/gemini-api/docs/openai)、[Gemini API 密钥](https://ai.google.dev/gemini-api/docs/api-key)。

## 聊天历史

发送问题及收到回答后自动保存聊天；重新打开程序或刷新页面后恢复上次对话。点击「对话操作 → 历史记录」可按标题或内容搜索、打开并继续旧对话，或点「新对话」另开一条。新建对话、修改服务设置不会删除之前的聊天。删除某条历史需要再点一次「确认删除」，不影响其他聊天或文献。

继续旧聊天会沿用该对话首次提问时的文献范围（「该对话文献」），不跟随当前列表中另一组勾选项改变；可切换范围另开对话。聊天完整内容在本地保留，续聊时向模型提供最近 12 条发言，连续的自动台词在此合为一条。支持最多 200 个对话、每个 1000 条消息、合计 20 MB；达到限制时提示整理历史，不会静默丢弃旧消息。

桌面版历史按文献库分别保存在 `ai-chats.json`，写入时保留上一次成功版本 `ai-chats.previous.json`，原文件损坏时不会自动覆盖。更换电脑或备份聊天时请复制这两个文件或整个文献库文件夹；原有文献 JSON 备份暂不包含单独的聊天文件。浏览器预览版保存于当前站点的本地数据库。历史文件仅包含消息和来源字段，不保存服务密钥。旧版本关闭前未保存的对话无法从历史中补回。

## 红莉栖的记忆库

「设置 → 语言」中的回复语言用于普通回复、自动台词和选项。原作检索在「设置 → 记忆库」中，接受三种语言，结果按所选回复语言显示。

- **相处记忆**按角色 ID `makise-kurisu` 在当前文献库的 `ai-chats.json` 中自动整理已完成的交流。程序保存对话及消息位置的索引，并识别清楚表达的自我称呼和偏好。程序按相关度回忆同一文献库、同一文献范围下的旧发言，每轮最多取三次交流。删除历史对话时，相应索引一并移除。旧版已保存的条目迁入角色名下。根目录的 `记忆库/relationship/makise-kurisu/` 保存按文献库分开的索引，原始对话仍只写入该文献库。
- **原作记忆**优先读取 Materia 根目录的 `记忆库/canon/makise-kurisu/corpus.json`，安装资源也带一份独立副本。每条记录有角色版本、作品、原文语言和来源。安装包纳入 19,772 条原作及转录记录，每条台词都有中、英、日版本，机器译文单独标记。生成回复时只取最多三个相关片段。

浏览器预览的个人记录保存在站点本地数据库。当前模型会收到与这轮问题有关的旧交流和原作片段。反重力对话由 Materia 每轮提供本地上下文，轮内文献工具继续复用本轮连接。

## 数据与能力边界

研究对话可调用四个本地只读工具：文献库概览、关键词检索、文献与笔记读取、原始性能记录比较。资料按问题检索后交给模型，并非一次上传全部文献库。每轮最多 4 个工具调用，每次提问最多 6 轮；结果包含截断提示。不同单位不换算、不平均，保留样品、条件、来源、限定符及原始误差。

发送问题会将问题、当前会话以及工具检索到的文献元数据、文献/关联标签笔记、性能参数发送到配置的服务。**不读取或上传 PDF 全文，不具备执行命令、访问任意文件、修改或删除文献的工具。** 模型回答仍需对照原始文献核实；来源列表表示本次实际检索的文献，不能自动保证模型每句话都正确。

桌面版的服务配置位于 Electron 用户配置目录的 `ai-agent.json`，与文献库及其备份分开。默认密钥仅在本次应用运行内保留；主动勾选「用系统加密记住密钥」后使用 Electron `safeStorage` 加密。密钥不回传给页面，不写入聊天记录、文献库、备份或仓库；关闭记住或点击清除会移除保存的密钥。系统加密不可用时只能使用会话密钥。更换服务地址会清空原服务密钥，避免误发。

浏览器预览版的密钥只在页面内存中保留，刷新后需重新填写；地址、模型和协议可以保存，历史聊天按上文说明保存。预览请求经过本机同源代理，不将服务密钥放进 URL，不绕过证书验证。仅允许 HTTPS 服务及本机 HTTP 服务，禁止重定向，支持取消、90 秒单次服务超时、300 秒桌面总超时及错误提示。

## 模块与验证

- `dist/ai-agent-core.js`：共享工具、范围隔离、来源跟踪与有界 Agent 循环。
- `dist/ai-agent.js` / `ai-agent.css`：对话侧栏、服务设置、停止操作和文献跳转。
- `desktop/agent.mjs`：兼容 API 适配、配置校验及加密密钥存储。
- `dist/agent-history.js` / `desktop/agent-history.mjs`：历史格式、容量校验与按文献库隔离的原子保存。
- `desktop/main.mjs` / `preload.cjs`：受限制的桌面通信接口。
- `desktop/agent-http.mjs`：浏览器预览的本机同源代理。
- `tests/agent.test.mjs`：范围、检索、模型循环、协议、密钥及代理测试。

PDF 划词和对照翻译沿用此处的服务地址、模型、协议和密钥，翻译请求不启用工具调用。研究对话仍仅使用文献目录、笔记和性能参数；翻译会把选文或主动翻译的页面文字发送到该服务，PDF 文件保留本地。生词本和译文纳入完整备份，密钥不纳入。使用方法见 [TRANSLATION.md](TRANSLATION.md)。


## 密钥状态与 HTTP 401（v1.4.1）

服务设置现在会显示密钥是已载入、仅本次有效，还是未载入。未勾选系统加密记住密钥时，关闭程序后会清除密钥，但仍保留地址和模型；下次需重新填写。DeepSeek 和 OpenAI 官方服务未载入密钥时会先打开设置并提示，聊天和翻译均不会发送空密钥请求。无密钥的本机服务和其他兼容服务仍可使用。

HTTP 401 表示服务认证失败：先确认密钥属于当前 API 地址并仍有效，再在设置中替换保存。HTTP 403 则检查账号和模型访问权限。程序不展示服务返回的原始错误正文，避免其中包含密钥。粘贴带 Bearer 前缀的密钥时会自动移除重复前缀。


## 厂商预设与模型发现（v1.5.2）

内置 DeepSeek、通义千问（中国内地 / 新加坡）、Kimi、智谱 GLM、豆包 / 火山方舟、百度千帆、腾讯混元、MiniMax、OpenAI、Anthropic Claude、Google Gemini、xAI Grok、Mistral AI、Groq、硅基流动和 OpenRouter。预设仅包含官方服务地址和协议，不包含固定模型 ID 或密钥。厂商提供兼容模型接口时会自动获取；未开放接口、套餐端点不同、需业务空间或地区地址时，请手动填写模型，或使用自定义地址。密钥应对应所选站点，预设不包含订阅或 Coding Plan 的专用地址。

查询返回为空、认证失败、网络超时、接口不支持或格式异常时显示具体原因，不伪造成功列表。可随时刷新；切换厂商或更换密钥时取消旧查询，迟到的结果不会混入新服务。切换厂商会清空输入中的密钥与模型，原有已保存配置在点击保存前继续生效；旧服务密钥只可复用于相同地址。旧模型不在新列表中时仍保留，标注为“当前设置，列表未确认”。

OpenAI 预设采用 Responses；Gemini 采用 Google 的 OpenAI 兼容接口；Claude 使用原生 Messages 与模型列表接口，保留工具调用与结果的对应关系。兼容接口保留工具轮次需要的思考字段和签名。现有自定义配置的地址、模型、协议及密钥存储方式保持不变。新旧设置共用本地加密存储，模型列表只在内存中使用。

模型查询不跟随重定向、不使用厂商响应提供的跳转 URL，不在 URL 中携带密钥；支持受限分页、取消、30 秒查询超时及响应大小限制。错误不显示服务原始正文，公开设置不返回完整密钥。浏览器版仍使用本机同源代理，密钥仅在当前页面内存中保留。
