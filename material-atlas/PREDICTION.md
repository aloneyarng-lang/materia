# 材料机器学习与性能预测

主页第五个“材料预测”模块面向通用材料数值回归。它可处理粉末、块体、薄膜、陶瓷、聚合物、半导体、电极、催化剂等预设类型，也允许直接填写自定义材料类型。所有导入、训练和预测在本机完成，不调用 AI 服务。

## 支持的数据

- 成分表达可选择 at.%、wt.%、mol.% 或化学计量式。百分比模式要求元素合计为 100%；化学计量式模式支持 `LiFePO4`、`Al2O3` 等普通式并自动转成原子分数。
- 输入描述符可以是数值或分类字段，包括结构、相、粒径、晶粒、厚度、合成与退火条件、计算参数、测试条件等。可按任务自行新增。
- 预测目标必须是确定的数值，可使用内置物性，也可新增形成能、带隙、容量、催化活性或自己的性能定义。
- 同名但单位、计算方法、测试条件或物理含义不同的目标必须拆成独立字段。程序不会猜测或自动换算单位。

## 使用流程

1. 在“数据集”下载 CSV 模板，或导入 XLSX、CSV、TSV。
2. 选择工作表和表头行，核对材料类型、成分表达、列映射与单位。可将列映射为成分、元素含量、输入描述符、数值目标或来源。
3. 预览导入报告。不等式、区间、近似值、带误差值和未展开变量不会自动成为确定标签；缺失目标不会补零。
4. 到“模型训练”选择完全相同的材料类型和成分表达范围，再选择数据集与目标。至少需要 15 条有效标签、5 组不同成分。
5. 在“材料预测”填写成分和模型实际使用的描述符。未训练的目标保持“待训练”。
6. 在“目标与描述符”新增字段。预测目标还可指定训练和预测时必须提供的描述符。

Excel 公式只读取文件中已保存的缓存值，不执行公式，请先在 Excel 中重新计算并核对。

## 模型与验证

每个数值目标独立训练可序列化的本地 Extra Trees 集成回归模型，最终模型使用 64 棵树。不同材料类型和成分表达方式严格分开建模；跨数据集完全相同的成分、输入和目标不会重复计入同一目标。

采用固定种子的 5 折分组交叉验证，相同成分不跨训练折与测试折；也可把相同来源与相同成分的连通组一起分组。所有缺失值处理和分类编码都在每个训练折内部拟合。模型只有在折外 MAE 优于训练折均值基线时才启用。

结果显示 MAE、RMSE、R²、90% 折外绝对误差分位数和主要输入。单次预测同时给出“预测值 ± 历史 P90 绝对误差”的经验范围；这不是统计置信区间，也不代表实验确认。模型还会提示未见过的元素或类别、缺失的必要描述符，以及元素含量或数值描述符超出训练范围。

“主要输入”按树节点使用频率汇总，只用于解释模型依赖了哪些输入，不等同于因果关系或严格的特征归因。

如果没有可用 ΔTx 模型但 Tg、Tx 均预测成功，仍会显示由二者之差计算的 ΔTx，并标明来源。预测结果不会加入真实训练标签。新增数据不会自动更新模型；移除数据集会停用依赖模型。

## 旧版兼容

2.1/2.2 创建的非晶粉末和粉芯数据集、模型及自定义字段可以直接继续使用。原来的 `powder`、`core`、at.% 与 wt.% 标识保持不变；升级只扩展材料范围、成分表达、描述符和结果解释，不删除旧数据。

## 保存与备份

桌面版使用当前文献库下的 `prediction-workspace.json`，原子写入并保留上一版本 `prediction-workspace.previous.json`。文献库切换会等待保存；训练时请先完成或停止训练。

“数据集”可单独导出或恢复预测工作区，内容包括字段、数据集与模型。完整文献备份不含这个独立文件；备份预测成果请导出工作区，或退出程序后复制整个文献库文件夹。

## 检查

`npm run check`、`npm test` 和 `npm run verify:prediction`。界面检查只使用隔离的合成数据，不代表真实材料精度，也不会读取或修改用户实际文献库。
