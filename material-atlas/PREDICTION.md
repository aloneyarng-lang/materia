# Materia 2.4 · 材料机器学习

桌面版使用完整 Python + NumPy + SciPy + scikit-learn 运行环境。训练、验证和预测均在本机独立进程中运行，无需配置 AI 服务或安装系统 Python。新版训练不再调用手写 JavaScript 树模型。

## 算法与流程

提供 scikit-learn 官方实现的 ExtraTreesRegressor、RandomForestRegressor、HistGradientBoostingRegressor、GradientBoostingRegressor、Ridge、ElasticNet、SVR 和 MLPRegressor。可选择多个候选算法，标准或全面参数搜索、32–2048 棵集成树、1–32 个计算线程和随机种子。神经网络在当前训练数据上拟合，不是材料领域预训练大模型。

每个数值目标独立建模，材料类型与 at.% / wt.% / mol.% / 化学计量式严格分开。支持粉末、块体、薄膜、陶瓷、聚合物、电极、催化剂与自定义材料类型；可添加数值或分类描述符和任意数值目标。当前任务类型为表格数据回归，不包含分类、晶体图网络或分子动力学。

1. 在“数据集”导入 XLSX / CSV / TSV，核对表头、字段映射、成分表达和单位。
2. 数值标签必须来自实验或计算。不等式、区间、近似值、带误差值和未展开变量不会成为确定标签；缺失目标不会补零。Excel 公式只读文件中已保存的缓存结果。
3. 在“模型训练”选择材料范围、数据集、目标、候选算法与计算设置。至少需要 15 条有效标签及 5 个独立成分／来源连通分组；这是运行下限，并不保证数据足够支持可靠泛化。
4. 开始训练；进度显示当前外层验证折。可停止训练，已完成并保存的目标保留。
5. 查看训练报告，确认外层验证通过且误差足以区分研究候选，再到“材料预测”填写成分与描述符。

同名但单位、方法、测试条件或物理含义不同的目标应拆为独立字段。软件不猜测或换算单位。目标可指定必填数值／分类描述符，训练和预测都会检查。

## 配方特征与预测适用域

“模型训练 → 配方特征”可选自动比较、仅原始元素配比或原始配比加合金描述符。自动比较在每个内层训练折联合比较输入特征、算法和参数。筛选单独针对每个目标，只用当前训练折的标签，保留最多 8 个派生描述符。已录入的结构、工艺和测试条件继续参与训练。报告显示最终输入、入选描述符以及每折选中的配置。

合金描述符包括组分元素数、理想混合熵除以 R，以及原子序数、原子量、共价半径、电负性、元素熔点、价电子数的原子比例加权均值和标准差。质量百分比先用原子量换为原子比例来计算派生描述符，原始配比和工作区基准保持原样。元素性质缺值时跳过相应整列。质量百分比遇到无法换算的元素时，自动比较回退到原始配比。元素数据和许可证随应用打包，模型保存使用过的元素数值。

新模型输出到最近训练配方的距离，单位为当前输入基准的百分点。距离是各元素含量差绝对值之和的一半。参考值来自不同训练配方的最近邻距离第 95 百分位，用来提示配方偏离。它没有覆盖实验条件或模型误差，不替代原有各元素、工艺条件和历史误差提示。

方法参考 [Zhang 等的铜合金研究](https://doi.org/10.1016/j.actamat.2021.117118)、[matminer 元素特征](https://hackingmaterials.lbl.gov/matminer/matminer.featurizers.composition.html)和 [Matbench 嵌套验证](https://doi.org/10.1038/s41524-020-00406-3)。这套实现面向用户的数据与目标独立训练，铜合金论文的特征集和实验误差不直接迁移。其基于实验回填的贝叶斯合金设计属于下游候选优化。

## 防止数据泄漏与模型评估

采用外层 5 折、内层最多 3 折的嵌套分组交叉验证。外层各训练折内部独立比较算法和参数；外层测试数据不参与选型、调参或预处理拟合。成分相同的记录始终同组；选择“来源与成分”时，共享来源或成分的连通记录同组，多个来源以 ` | ` 分隔。

预处理使用 ColumnTransformer、Pipeline、SimpleImputer、StandardScaler 和 OneHotEncoder，目标标准化使用 TransformedTargetRegressor；这些处理均随当前训练折拟合。数值缺失值填补并加入缺失指示，分类缺失单独编码。跨数据集相同成分、输入与目标的重复记录不重复计数。

报告包括：

- 外层折外 MAE、RMSE、R²、中位数预测基线 MAE（另存均值基线）、P90 绝对误差；每折样本数、分组与最优参数。
- 实测／预测散点图与残差图。图中最多展示约 1000 点，CSV 与 JSON 保留全部折外记录、来源、数据集、行 ID 与分组。
- 全数据内层交叉验证的候选排名、折间标准差、训练 MAE 和耗时；该排名不能代替外层泛化评估。
- 外层测试折上的置换重要性（3 次置换、每折最多 200 条），按折平均。单位为目标单位，正值表示置换该输入后 MAE 增大，不表示因果关系。
- 最终参数、随机种子、数据 SHA-256 指纹、依赖版本、Python 版本、总耗时及库级警告。

最终模型在全部有效数据上重新选型、调参、拟合。外层指标评估的是整个选型流程，不是额外独立测试集上的最终模型成绩。新版在所选建模尺度上要求：外层 MAE 优于训练折中位数基线、折外 R² > 0，并且至少 3/5 折优于该基线，才可启用。旧模型保留训练当时的门槛，不能混同。均值基线仍在报告数据中作为兼容参考。

预测显示“预测值 ± 折外 P90 绝对误差”的经验误差带。这不是校准的统计置信区间，也不保证新材料的 90% 覆盖率。未见过的元素或类别、缺少必填字段会阻止该条预测；超出训练范围与可填补的缺失字段会提示。没有独立 ΔTx 模型时，可由成功预测的 Tx − Tg 计算并明确标记。

## 批量预测与模型管理

“材料预测 → 批量预测 CSV”接受 CSV / TSV：需要 `composition` 成分列，描述符列使用字段 ID 或已识别的名称。按当前材料类型和成分表达，使用所有启用目标生成结果 CSV，逐行保留错误、范围警告、模型 ID 与经验误差带。每批最多 30,000 行；预测结果不会加入训练标签。

新增数据不会自动重训；数据版本变化会提示重训。移除数据集会停用依赖模型。新模型通过验证后取代同范围同目标的活动模型，历史记录保留。可启用已通过验证且原始数据集仍存在的历史版本，也可移除不再需要的模型与报告。

## 保存、迁移和兼容

桌面版保存在当前文献库的 `prediction-workspace.json`，原子写入，上一版为 `prediction-workspace.previous.json`。工作区包含数据、字段、训练报告以及压缩的 skops 模型工件，可以在“数据集”单独导出／恢复。模型工件采用 SHA-256 校验与固定类型白名单，不使用任意 pickle 或 joblib 反序列化。加载时核对科学计算库版本；版本不同需使用原运行环境或重新训练。

当前工作区最多 30,000 条记录、300 个模型，JSON 文件最大 512 MiB；大模型会增加保存与备份时间和内存占用。复制整个软件目录和文献库可同时保留运行环境与模型。完整文献备份不包含这个独立预测文件，请单独导出工作区或复制整个文献库。

2.1–2.3 数据和已保存的旧 JavaScript 模型仍可读取、预测；记录中标明旧版自实现模型。新模型需要桌面 Python 引擎。网页预览可管理数据、查看报告和使用旧模型，不能训练新模型或执行 Python 模型推理。

## 开发与打包

- `npm run setup:ml`：从 Python 官方网站下载并核对嵌入式 Python 3.13.12 SHA-256，从 PyPI 安装 `ml/requirements.txt` 的固定版本依赖。开发准备步骤需要网络与已有 Python/pip。
- `npm run test:ml`：真实库训练、分组隔离、预处理泄漏检查、全部 8 种算法持久化、边界情况与批量预测测试。
- `npm test`、`npm run check`、`npm run verify:prediction`：应用回归、语法及实际 Python 引擎界面联调。
- `npm run build:exe`：验证源运行环境，将完整环境和许可证随程序打包，并再次检查暂存包引擎。缺少环境则构建失败，不发布空壳功能。

新增实现位于 `ml/engine.py`、`desktop/ml-engine.mjs`、`dist/prediction-report.js`；原有导入、材料字段和模块机制继续沿用。第三方包的许可证随运行环境中的 `.dist-info/licenses` 等原目录保留。

设计依据：[scikit-learn 分组交叉验证](https://scikit-learn.org/stable/modules/cross_validation.html)、[嵌套交叉验证](https://scikit-learn.org/stable/auto_examples/model_selection/plot_nested_cross_validation_iris.html)、[模型持久化](https://scikit-learn.org/stable/model_persistence.html)、[skops 安全持久化](https://skops.readthedocs.io/en/stable/persistence.html)。

导入预览会核对可识别的表头单位和成分基准。明确不一致时请按原表选择组分基准、换算源数据或映射至使用原单位的独立字段。完全相同的观测合并时保留各来源和原表行号，来源验证会使用全部关联来源。

## 铁基非晶研究流程（2026-11-06）

训练页先选择研究任务。铁基非晶路线默认只输入成分；纳米晶带材路线输入成分与已知工艺、测试条件。默认按来源与成分连通分组，规范化 DOI 链接和 DOI 前缀；预览显示每个目标的标签数、独立组数、缺来源数量。数据集勾选与训练参数在重绘时保留。

工艺模式使用明确列出的设计时输入，不自动纳入晶粒尺寸、物相或未分类的自定义表征量。全部字段模式仍可选，但这些输入必须在预测时已知。不能用 Hc 阈值推断物相后再预测 Hc。目标声明的必填输入不能被场景选择悄悄排除。

建模尺度默认按性能：Hc / hcOe 用自然对数，其余目标保留原单位；可手动选择。对数要求所有标签严格正值，零值、负值不会加常数或被默默删除。对数是确定性变换；标准化及监督特征选择仍在训练折内拟合。算法在对数 MAE 上选型，预测反变换为原单位；该点估计是对数空间预测的指数，不保证是原尺度条件均值。

主表、散点、CSV 保留原单位 MAE、RMSE、R²，同时报告对数 R²、MAE 和倍数误差。对数模型误差带为预测值 ×/÷ exp(P90(|ln y − ln ŷ|))，不会给出负的 Hc 下限。它仍是折外历史误差，未证明对新实验有 90% 覆盖率。置换重要性和候选排名使用实际建模尺度。

新增审计：相同输入而标签不同的组、输入覆盖率、来源缺失、最大来源连通组；不平均冲突标签。形态待核和 Hc 无工艺信息会在报告及预测中持续提示。模型报告的“仅适合初步筛选”以所选尺度 R² < 0.5 为阅读提示，不是领域合格标准，更不是实验精度保证。

依据：Lu 等（10.1038/s41524-020-00460-x）、Wang 等（10.1016/j.actamat.2020.05.006）、Li 等（10.1016/S1003-6326(22)66101-6）、Li 等 GMTDL（10.1088/1674-1056/ae5b5f）。算法名称不决定最优方案；本实现按实际可用输入与分组验证结果决定可用性。作者 GMTDL 代码的三个任务分别随机划分，需要额外统一成分/来源划分才能评估未见配方，未直接复制到正式引擎。
