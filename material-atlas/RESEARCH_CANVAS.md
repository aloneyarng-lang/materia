# 研究画布：思维导图、关系图与规则生成

从左侧「研究画布」或窄工具栏的关系图标进入。可创建多张独立画布；初次进入不会自动加入示例，点击「从材料研究示例开始」才创建示例内容。

## 图形编辑

- 默认在空白处拖动框选多个节点，拖动任意选中节点即可整体移动。Ctrl / Shift 点击增减选择，Ctrl+A 全选，Esc 取消选择或当前拖动。
- 右键拖动或按住空格拖动平移画布，也可切换顶部「平移画布」工具；滚轮与右下角按钮缩放，「适应画布」显示全图。
- 右键节点可选择同组或下游节点、从该节点拉线、添加子节点、编辑或删除所选节点。批量删除会一并移除相关连线，可撤销恢复。
- 「新节点」在视图中心添加独立节点；右侧「添加子节点」连接当前节点和新节点。
- 「连接节点」启用连线模式，依次点起点、终点；选中节点时直接以它作为起点。Esc 退出连线模式。
- 选中节点后可编辑文字、研究笔记、形状、颜色、分组、图片、文献与标签笔记链接。相同分组名自动显示共同的边界。
- 选中连线可编辑关系文字、虚线及箭头。Delete 删除当前节点或连线；删除节点同时删除它的连接，其他节点与文献保留。
- Ctrl+Z 撤销、Ctrl+Shift+Z 或 Ctrl+Y 重做。删除整张画布需要再次点击确认，并可在左侧撤销删除。
- 思维导图支持左右、向右、向左、向下展开。右下角减号左侧的「自动整理画布」执行智能紧凑整理，旁边的箭头可切换其他排法。全图整理后适应视图，仅整理所选时其他节点保持原位。节点内容、笔记、图片和连线保持完整，可通过撤销恢复原布局与视图。存在规则草稿时，先应用或还原代码再整理。

工具栏的放大镜或 Ctrl/⌘+F 可按节点文字、笔记、分组、标签或 ID 查找，按 Enter 依次定位结果。选中一个或多个节点后，可以从属性栏或右键菜单复制节点，保留图片、属性以及所选节点之间的连线。

「智能紧凑整理」会按当前画布宽高选择排法，给分组边框和标题留空间，把过长的单线流程折成多行。网格按节点实际尺寸留空。使用「仅整理所选节点」时，整理后的节点会尽量留在原来的区域，并避开未选中的节点。

- **中心辐射**。把相连的节点按到中心的距离向外排开。只选中一个节点时，它会成为所在关系网的中心。
- **分组泳道**。每个分组占一个横向条带，组内节点由左向右排列，长组内换行。
- **连通分区**。依据连线把互相连通的节点摆在一起，适合一张画布上有多个互不相连的子图。
- **瀑布流**。把下一张卡片放入最短的一列，适合混排图片、长文字和短标签。

## 规则代码

点击「规则代码」，编辑后点「预览生成」，确认再点「应用到画布」。预览不替换当前图形；错误显示具体行号，草稿与原图分别保存。Ctrl+Enter 预览，Ctrl+Shift+Enter 应用。「还原代码」放弃规则草稿并显示当前图形的规则。

图形编辑会同步更新规则，包含节点坐标。存在未应用的规则草稿时，请先应用或还原，再继续编辑图形，避免两份内容互相覆盖。

可以直接粘贴 AI 输出的单个代码块（语言标记为 `materia-canvas`、`mcanvas` 或 `text`），也可使用纯规则文本。

只想修改已有画布的一部分时，点击「局部更新」或在代码编辑器中以 `update` 开头。用节点属性里的 ID 指定要改的节点。`node` 可改已有节点的文字或新增节点，`style` 可只指定要改的属性。已存在的连线可以修改文字和样式。其余节点、连线、图片和坐标会保留。应用后，编辑器会重新显示完整画布的规则。

```mcanvas
update
theme blueprint
style process shape=parallelogram color=blue
node review "核对测试条件" shape=octagon color=gold
image-size structure large
ungroup [process]
review -> performance : "检查可比性"
```

基本语法：每行一条规则；文字使用 JSON 双引号字符串，可用 `\n` 换行、`\"` 输入引号。空行及以 `//` 或 `#` 开头的行是注释。

```text
canvas "高熵合金研究"
layout mindmap
direction right

node root "强度与塑性协同"
node composition "成分设计"
node process "热处理"
node structure "析出相"
node performance "力学性能"

root -> composition
root -> process
process -> structure : "调控"
structure -> performance : "影响"

style structure shape=hexagon color=purple
note structure "需要进一步确认尺寸与分布。"
group "实验变量" [composition, process]
```

| 规则 | 含义 |
| --- | --- |
| `canvas "名称"` | 画布名，最多一条 |
| `layout mindmap` / `layout free` | 思维导图 / 自由关系 |
| `direction both` / `right` / `left` / `down` | 展开方向 |
| `node id "文字"` | 定义节点，ID 唯一且以字母或下划线开头，可含数字、短横线 |
| `a -> b : "说明"` | 从 a 指向 b，关系文字可省略 |
| `style a shape=hexagon color=purple` | 节点外观 |
| `note a "研究笔记"` | 节点详细说明 |
| `group "实验变量" [a, b]` | 节点分组 |
| `link a paper="文献ID"` | 关联库内文献，点击打开详情 |
| `link a tag="标签名称"` | 关联现有的标签笔记，可打开并添加多条笔记 |
| `image a "asset:图片ID"` | 引用当前画布已有的图片资源 |
| `image a none` | 移除节点的图片 |
| `image-size a small` | 设置图片显示大小，支持 `small`、`medium`、`large` |
| `position a 100 200` | 节点中心坐标，单位为画布坐标 |
| `edge-style a b dashed=true arrow=false` | 连线虚实与箭头 |
| `theme system` / `paper` / `blueprint` / `forest` / `night` | 画布主题 |
| `style a theme=night` | 设置节点主题，使用 `inherit` 恢复跟随画布 |
| `node id "文字" shape=pill color=blue` | 定义节点时同时设置形状和颜色 |
| `ungroup [a, b]` | 解除指定节点的分组 |
| `remove edge a -> b` | 在 `update` 中删除一条有方向的连线 |
| `remove node a` | 在 `update` 中删除节点及其连线 |
| `empty` | 定义一张没有节点的完整画布 |

形状支持 `roundrect`（圆角卡片）、`rect`（矩形）、`ellipse`（椭圆）、`diamond`（菱形）、`hexagon`（六边形）、`pill`（胶囊形）、`parallelogram`（平行四边形）、`document`（折角文档）和 `octagon`（八边形）。例如可用胶囊形标记起止，用平行四边形表示数据输入，用折角文档表示参考资料，用八边形标记待复核的结论。颜色支持 `accent`、`blue`、`purple`、`gold`、`green`、`red`、`gray` 或 `#RRGGBB`。强调色、背景、边线与字体跟随当前主题，切换主题保留布局。

同一方向的两个节点之间只保留一条连线；可添加反向连线或交叉连线。思维导图自动布局会从关系中选取树状骨架来排版，额外关系仍全部显示。节点 ID 不变时，重新生成会保留其手工坐标；新节点自动安排。显式的 `position` 优先。要重新排版，请应用代码后点击右下角「自动整理画布」。

## 画布主题

在工具栏的主题下拉菜单选择「跟随应用」「暖纸」「蓝图」「森林」或「夜幕」。每张画布保存自己的主题，完整 JSON 会保留该选择，SVG 和 PNG 使用导出时的画布配色。旧画布默认跟随应用主题。

选中一个或多个节点后，可以在属性栏设置「节点主题」。它控制该节点的填充色、文字和预设描边颜色，图片保持原样。节点默认跟随画布。也可以用 `style a theme=night` 修改单个节点，或者用 `node a "待复核" shape=octagon theme=night` 创建带主题的节点。

## 图片、导入与导出

工具栏的「新建图片节点」可一次选取多张图片。在画布空白处拖放或粘贴图片也能新建节点。把图片拖到已有节点上可以添加或替换该节点的图片。图片会保持比例，可在节点属性中选择三档显示尺寸。

图片支持 PNG、JPEG、WebP，上传时压缩到最长边 1280 像素，作为画布内嵌资源保存。资源 ID 显示在图片下方，可通过规则让多个节点引用同一张图。需要连同图片一起迁移时，导出完整画布 JSON。

「导入与导出」支持：

- 完整画布 `.materia-canvas.json`：包含图形、笔记、布局、规则草稿与图片，适合备份和分享。导入创建新副本，不覆盖已有画布。
- 规则文本 `.canvas.md`：可由其他 AI 按上述规范生成并导入，也可直接粘贴。图片资源请使用完整 JSON 包一起传递。
- SVG：矢量节点、文字、连线与内嵌图片，采用当前主题；其他电脑缺少相应字体时使用后备字体。
- PNG：完整画布图片，自动适配导出尺寸，不受当前缩放或可见范围限制。

## 本地保存

桌面版将全部画布写在当前文献库文件夹的 `research-canvases.json`，上一版保存在 `research-canvases.previous.json`。保存采用临时文件原子替换，与文献元数据及 PDF 分开；编辑自动保存，返回文献库和关闭桌面窗口时会等待保存完成。保存失败时保留编辑内容和窗口，可点击「立即保存」重试。

浏览器预览版使用本浏览器本地数据库。迁移请导出完整画布 JSON，或复制整个桌面文献库文件夹；原有的文献 JSON 备份目前不包含独立画布文件。

每张画布最多 300 个节点、700 条连线、24 张图片；单张文档限 12 MB，画布库合计限 40 MB、50 张画布。文本、规则草稿与全部图片随完整包导出；文献链接保留 ID，目标库不存在该文献时显示缺失提示。
