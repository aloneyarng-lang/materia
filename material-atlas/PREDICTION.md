# 非晶粉末性能预测

主页第五个“性能预测”标签位于星图、文献、材料、笔记的右侧。所有导入、训练和预测在本机完成，不调用 AI 服务。

## 使用

1. 在“数据集”中下载 CSV 模板，填写自己的实测数据；也可直接导入 XLSX、CSV 或 TSV。
2. 选择工作表与表头行，核对列映射、单位、百分比类型、样品形态。元素百分比可以采用一个成分式列（如 `Fe80Si9B11`）或分开的元素列。不要同时使用两种方式。
3. 预览导入结果。区间、不等式、近似值、带误差值和未确定元素不会自动成为确定数值标签；跳过原因可查看。缺失性能不填成零。Excel 公式只读取保存的缓存值，不执行公式，请先在 Excel 中重算并核对。
4. 到“模型训练”选择数据集与性能。至少需要 15 条有效标签、5 组不同成分。参考形态数据不用于粉末／粉芯训练；原子百分比、质量百分比和不同形态分开建模。
5. 在“配方预测”输入成分及模型需要的条件。可以直接输入带百分比的成分式，也可以逐个添加元素。未训练的性能显示待训练。
6. 在“性能与输入字段”新增性能或输入条件，再导入对应数据并重训。

## 数据定义

- 成分百分比明确选择 at.% 或 wt.%，不自动互换。元素合计允许 0.15 个百分点以内的舍入偏差，再归一化到 100%。未提供百分比的化学计量式、未展开变量和余量表达式需要先明确展开。
- 表头单位仅供人工核对，不自动转换。原表 `HV(GPa)` 与接近 1000 的硬度数值需要核查原文；HV 与 GPa 不可直接混用。
- `dc` 是参考形态的临界尺寸，区别于粉末粒径 D50。力学性能的 `B` 指体积模量，区别于 `Bs`。
- 磁芯损耗训练要求每条记录包含频率和磁感应强度；有效磁导率要求频率；直流偏置保持率要求偏置磁场。可增加温度、粒径分布、包覆和工艺等字段。
- 不同测试方法或不同含义的同名指标应新建独立字段。新的数值性能无需修改页面代码。

## 训练与结果解释

第一版使用可序列化的本地随机阈值树集成回归，最终模型含 64 棵树。每个性能独立训练，因此某性能缺失不影响其他性能。跨数据集完全相同的成分、输入与目标值不会重复计入该目标的训练样本。

采用固定种子的 5 折分组交叉验证，同一成分不跨训练组与测试组。可选择把相同来源以及相同成分的连通组一起分组；独立组不足 5 组时停止训练。缺失值处理和分类编码在每个训练折内部拟合。验证误差没有优于训练折均值基线的模型不启用；通过后保留已有模型为历史版本。

MAE、RMSE 和 R² 来自折外预测。MAE 不是单次预测的置信区间，通过内部验证也不代表实验确认。未见过的元素、分类条件以及缺失的必要输入会阻止对应性能预测；超出数值训练范围会显示提示。

如果没有可用 ΔTx 模型但 Tg、Tx 均预测成功，会显示由二者之差计算的 ΔTx，并标明来源。预测结果不会加入实验训练标签。

新增数据不会自动更新模型，页面会提示数据变更。移除数据集会停用依赖它的模型。

## 保存与备份

桌面版使用当前文献库下的 `prediction-workspace.json`，原子写入并保留上一版本 `prediction-workspace.previous.json`。文献库切换会等待正在进行的保存；训练时请先停止或完成训练，再切换文献库或关闭窗口。浏览器预览使用当前浏览器的本地存储接口。

“数据集”提供预测工作区单独导出与恢复，包含字段、数据集与模型；恢复会要求确认替换。原有文献备份不含这个独立预测文件，备份预测成果请使用“导出预测工作区”，或退出程序后复制整个文献库文件夹。单个数据集、模型验证明细及预测结果也可导出为 CSV。

## 检查

`npm run check`、`npm test` 和 `npm run verify:prediction`。界面检查使用隔离的合成数据，仅测试功能流程，不代表真实材料精度，也不读取或修改用户的实际文献库。
